# Hướng dẫn dữ liệu

Dự án sử dụng bộ dữ liệu UCI Online Retail.

## File dữ liệu gốc

Tên file:

`Online Retail.xlsx`

Nguồn:

UCI Machine Learning Repository, Online Retail Dataset.

## Quy mô đã nghiệm thu

- Dữ liệu thô: 541.909 dòng.
- Dữ liệu sạch: 524.878 dòng.
- Dữ liệu đủ điều kiện RFM: 392.692 dòng.
- Khách hàng RFM: 4.338.

## Cách sử dụng

1. Tải file `Online Retail.xlsx` từ UCI.
2. Đặt file vào thư mục `data/raw/`.
3. Chạy notebook theo thứ tự từ đầu đến cuối.
4. Không thay đổi tên file raw trong quá trình chạy.

## Lưu ý

File dữ liệu gốc không được đưa trực tiếp vào repository nếu vượt giới hạn dung lượng. Repository chỉ lưu mã nguồn, hướng dẫn và các output nhỏ cần thiết.
